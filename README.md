# Vin-Car — новий фронтенд каталогу

Новий вигляд (дизайн у стилі mobile.de) для каталогу автомобілів Vin-Car.
**Бекенд і базу даних не змінює** — читає ваш існуючий API та показує дані у новому
оформленні. Це «обличчя» сайту: каталог з фільтрами + сторінка автомобіля з галереєю.

Подарунок від VinCarGroup. Користуйтесь вільно.

## Що всередині
- `server.mjs` — легкий Node-сервер без залежностей. Він:
  - тримає токен у себе (на сервері) і ходить у ваш API — **токен у браузер не потрапляє**;
  - кешує список авто (за замовчуванням 10 хв), щоб не смикати API на кожного відвідувача;
  - розшифровує коди (паливо/коробка/локація) і віддає фронту чистий JSON;
  - **перефарбовані елементи (paintwork) у публічну видачу НЕ включає** — цю інформацію
    у вас бачать лише залогінені клієнти, тож на публічній сторінці її немає.
- `public/` — сам сайт: `index.html`, `styles.css`, `app.js` (каталог + сторінка авто).

## Джерела даних (ендпоінти вашого API, які використовуються)
- `GET /api/v1/autos?per-page=30&page=N` — список авто (пагінація по `_links.next`).
- `GET /api/v1/autos/{id}` — картка одного авто (характеристики, всі фото).
Авторизація — заголовок `Authorization: Bearer <токен>`.

## Запуск

### Варіант 1 — Node напряму (Node 20+)
```bash
cp .env.example .env      # вписати ваш VINCAR_TOKEN
npm start                 # або: node server.mjs
```
Відкриється на `http://localhost:8810`.

### Варіант 2 — Docker
```bash
docker build -t vincar-site .
docker run -d --name vincar-site --restart unless-stopped \
  --env-file .env -p 8810:8810 vincar-site
```

Далі направте потрібний домен/піддомен на цей застосунок (ваш reverse-proxy: nginx/Caddy
→ `127.0.0.1:8810` або ім'я контейнера).

## Підключити до ваших даних напряму (за бажанням)
Зараз застосунок читає дані через ваш HTTP API з токеном. Якщо зручніше — можна
підключити його прямо до вашої бази: у `server.mjs` є дві функції-джерела —
`getCars()` (список) і `getDetail(id)` (картка). Замініть у них виклик `apiGet(...)`
на ваш запит до БД, зберігши формат об'єктів (`mapCar` / `mapDetail`) — і фронт
працюватиме без токена взагалі.

## Налаштування
- Кеш списку — константа `TTL` у `server.mjs` (за замовчуванням 10 хв).
- Телефон/контакти у шапці — `public/index.html`.
- Кольори/шрифти — `public/styles.css` (палітра у `:root` зверху).

Питання по коду — можемо підказати.
